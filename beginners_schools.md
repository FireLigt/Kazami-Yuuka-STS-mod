# Beginner Schools — YuukaMod Starter Decks

Three archetypes ordered from easiest to hardest. Each lists key cards to pick, how to play, and what to avoid.

---

## School 1: Magic Cannon (Easiest)

**How it works:** Cannons auto-play Danmaku cards from your hand for free. You play big cannons, they trigger your small danmaku — effortless damage scaling.

### Core Cards (must-pick — build around these)

| Card | Why | Quantity |
|------|-----|----------|
| **Magic_cannon** (2c 16 AoE, MAGICCANNON) | Your main gun. Triggers all Danmaku in hand. | As many as you see |
| **Second_magic_cannon** (2c 16 AoE, MAGICCANNON) | Same. Second barrel. | As many as you see |
| **Small_magic_cannon** (1c 5/8 AoE, MAGICCANNON) | Early-game filler cannon. Still triggers Danmaku. Remove later. | 1-2 early |
| **Danmaku** (1c 7/11, DANMAKU) | Ammo. Cannons fire it for free. Without these, cannons do nothing. | 3-4 |
| **Ready** (0c, fetch MAGICCANNON from draw pile) | Tutors your guns. Without this you might draw no cannon. | 1-2 |
| **Reload** (0c, move all DANMAKU from discard→draw pile) | Recycles ammo. Prevents running dry. | 1 |

### Support Cards (nice additions)

| Card | Why |
|------|-----|
| **Big_magic_cannon** (3c 28 AoE, upgrade: Weak all) | Bigger gun. |
| **Large_magic_cannon** (4c 40 AoE + 2 Vuln all) | Biggest gun before Ultra. |
| **Giant_magic_cannon** (5c 45/60 AoE, min 3E) | Affordable nuke if you have energy. |
| **Ultra_magic_cannon** (6c 100/150 AoE, MAGICCANNON) | Ultimate finisher. Gets cheaper each draw. |
| **Double_magic_cannon** (0c, next cannon plays twice) | Pairs with any big cannon for double damage. |
| **Gunmaku** (1c 2×5 hits, DANMAKU) | Multi-hit ammo. Scales with Strength. |
| **Big_danmaku** (2c 10/14, DANMAKU) | More ammo if you're short on Danmaku. |
| **Danmaku_festival** (4c power, DANMAKU→gain 1E+draw1) | Turns cannon turns into massive value. Expensive. |
| **Power_deterrence** (1c draw 3/4, Weak all per cannon) | Draws into cannons, mass debuff. |
| **Flower_Shooting** (2c 14/20, triggers ALL auto-targets) | Triggers both Danmaku **and** Plants. |
| **Fragrance** (0c E+draw, 2 uses) | Free energy and draw. Good everywhere. |
| **Contempt** (1c, all cards -1c this turn) | Makes expensive cannons playable. |
| **Smiling** (0c heal 4/6) | Sustain for hallway fights. |
| **Prepare** (1c, temp Str = DANMAKU count in deck) | Big burst turn with enough Danmaku. Retain on upgrade. |
| **Puncture_wound** (1c, next cannon reduces ALL enemies' Str by its damage) | Game-winner vs scaling bosses. Stacks with Ultra MC (150 Str loss). |
| **Mature_gang** (2c power, draw 2/3 extra per turn) | Best generic draw power. Good in any deck. |

### Anti-synergy — AVOID

| Card | Why It Hurts |
|------|-------------|
| **Preemptive_attack** | PHYSICAL_ARTS with no tag synergy. Doesn't help cannons fire. Clogs hand. |
| **Straight_punch** | PHYSICAL_ARTS — wastes hand space and energy. |
| **Uppercut** | Same. You don't need Vuln because cannons are AoE anyway. |
| **Backspin_kick** | Single-target PHYSICAL_ARTS. Your deck is AoE-focused. |
| **Finishing_move** | Ends your turn — you want to play *more* cannons, not stop. |
| **Ankensatsu** | 3-cost PHYSICAL_ARTS. Doesn't trigger anything. |
| **Bridge_suplex** | Chain mechanic irrelevant to cannons. |
| **Uninterrupted_combo** | PHYSICAL_ARTS multi-hit. No cannon synergy. |
| **Sunflower** | FLOWER — triggers Plants, not Danmaku. Clog in cannon deck. |
| **Twin_sunflower** | Same. Gives energy but Plants don't help cannons. |
| **Flower_pot** | PLANT — consumes hand space for block you could get elsewhere. |
| **Wall_nut** | PLANT — takes up a draw slot that could be a cannon. |
| **Plantern** | PLANT — good block but draws you away from cannon engine. |
| **Suika** | PLANT — generates Small_suikas that dilute your draw pile. |
| **Crazy_yuuka** | Power that generates PLANTS. You don't want plants in hand. |
| **Fertilizer** | FLOWER support. Useless without FLOWERS. |
| **Gensou_shunka** | Generates FLOWERS each turn. Clogs hand. |
| **Seamless_combo** | PHYSICAL_ARTS engine. Dead card. |
| **Meet_Retsu** | PHYSICAL_ARTS copy engine. Dead card. |
| **Worthy_opponent** | 3c power — too expensive, doesn't help cannons directly. |

## School 2: Physical Arts (Straightforward)

**How it works:** Play PHYSICAL_ARTS cards in sequence. Many get cheaper or stronger when chained. Scale Strength for big multi-hit finishers.

### Core Cards (must-pick — build around these)

| Card | Why | Quantity |
|------|-----|----------|
| **Preemptive_attack** (1c 6/9, gains +1dmg permanently) | Scales infinitely. Wins long fights. | Every copy |
| **Straight_punch** (1c 8/12, retrieve random from discard) | Provides consistency — gets back your key PHYSICAL_ARTS. | 2 |
| **Uppercut** (1c 6/8 + 1/2 Vuln) | Cheap enabler for chains. Vuln amplifies all your attacks. | 1-2 |
| **Backspin_kick** (2c 10/14 + Vuln + shackle Str) | All-rounder: damage + debuff + defense (shackle). | 1-2 |
| **Charge_up** (1c power, PHYSICAL_ARTS→draw+discount) | Your engine. Without it chains run out of gas. | 1 |

### Support Cards (nice additions)

| Card | Why |
|------|-----|
| **Ankensatsu** (3c 23/27, refund 1E, chain: +2E more) | Big hit + energy refund. Upgrade makes it net-0 when chained. |
| **Bridge_suplex** (2c 16/20, chain: -1c) | Upgrade makes it 1c base, chain = 0c for big damage. |
| **Finishing_move** (2c 15/20, chain: ×2 + Weak, ends turn) | Nuke. Play last. |
| **Uninterrupted_combo** (2c 13×1 damage hits, PHYSICAL_ARTS) | Each Str adds 13 total damage. Premium Str scaling. |
| **Contempt** (1c, all cards -1c this turn) | Enables bigger turns. |
| **Low_speed** (1c, -1 Dex, +4/6 Str) | Excellent Str gain. Dex loss is your only downside. |
| **Intimidation** (0c, +1 Str, 2 Weak) | Free permanent Strength. Keep from starter deck. |
| **Meet_Retsu** (2c power, every 2nd/3rd PHYSICAL_ARTS→copy) | Doubles your chains. |
| **Seamless_combo** (2c power, PHYSICAL_ARTS→draw another) | Infinite chains. Upgrade discounts drawn card. |
| **Worthy_opponent** (3c power, every card→+1 Str) | Insane Str scaling. Expensive. |
| **Morning_haze** (2c power, gain Str from HP lost) | Extra Str if you take hits. |
| **Getting_over_it** (2c power, start-of-turn +2/3 Str) | Consistency. Lose on HP loss — play block. |
| **Fragrance** (0c E+draw, 2 uses) | Free energy for more punches. |
| **Smiling** (0c heal 4/6) | Sustain. |
| **Parasol** (2c power, each card = 1/2 block) | Block engine for this school — you play many cards per turn. |
| **Punch_in_face** (3c 22/26 + Stun, PHYSICAL_ARTS, Exhaust) | Stun removes any enemy for a turn. Game-winner in boss fights. |
| **Mature_gang** (2c power, draw 2/3 extra per turn) | Best generic draw power. Good in any deck. |

### Anti-synergy — AVOID

| Card | Why It Hurts |
|------|-------------|
| **Magic_cannon** | Not PHYSICAL_ARTS. Doesn't chain. Takes up draw/energy. |
| **Second_magic_cannon** | Same. |
| **Small_magic_cannon** | Same. Even weaker version of the same problem. |
| **Big_magic_cannon** | Same. |
| **Danmaku** | Not PHYSICAL_ARTS. Dead in hand. |
| **Gunmaku** | DANMAKU tag, not PHYSICAL_ARTS. No chain benefit. |
| **Big_danmaku** | Same. Avoid any DANMAKU cards. |
| **Ready** | Tutors cannons. Useless if you have none. |
| **Reload** | Recycles DANMAKU. Useless. |
| **Double_magic_cannon** | Dead card. |
| **Sunflower** | FLOWER — doesn't chain, triggers nothing relevant. |
| **Twin_sunflower** | Same. Energy is nice but the card slot is wasted. |
| **Flower_pot** | PLANT — takes hand space. |
| **Wall_nut** | PLANT — pure block you could get from Parasol or generic block. |
| **Plantern** | PLANT — no PHYSICAL_ARTS tag, breaks chains. |
| **Suika** | PLANT — generates Small_suika that dilute draw pile. |
| **Crazy_yuuka** | Generates PLANTS. Clogs your hand with non-PHYSICAL_ARTS cards. |
| **Fertilizer** | FLOWER support. Dead in this school. |
| **Gensou_shunka** | Generates FLOWERS each turn. Clogs hand. |
| **Blossoming_of_Gensokyo** | No PHYSICAL_ARTS tag. No chain synergy. |
| **Watering** | No PHYSICAL_ARTS tag. Just deck shuffle. |

## School 3: Flower Garden (Moderate)

**How it works:** Flowers give energy per turn. Plants auto-trigger when a FLOWER is played. Generate and recurse plants for infinite value.

### Core Cards (must-pick — build around these)

| Card | Why | Quantity |
|------|-----|----------|
| **Sunflower** (0c, 2E over 2 turns, FLOWER, Exhaust) | Energy battery. Upgrade to 0c. Triggers Plants. | 2-3 |
| **Twin_sunflower** (1c, 4E over 2 turns, FLOWER, Exhaust) | Bigger energy battery. Upgrade to 1c. | 1-2 |
| **Flower_pot** (1c 6/9 block, FLOWER) | Cheap FLOWER to trigger Plants. Also blocks. | 2 |
| **Wall_nut** (1c 9/12 block, PLANT) | Efficient block that gets auto-played by Flowers. | 1-2 |
| **Plantern** (1c scry 3 + block, PLANT) | Scry + big block. Gets auto-played. | 1-2 |

### Support Cards (nice additions)

| Card | Why |
|------|-----|
| **Suika** (3c 30/40 dmg, PLANT, generates Small_suika) | Big damage + infinite merge loop. Auto-triggered = 15/20 dmg, stays in hand. Mandatory if you find it. |
| **Repeater** (2c 6×2 hits, PLANT) | Multi-hit damage. Auto-triggered. |
| **Tall_nut** (2c 13/17 block, PLANT) | More block, gets auto-played. |
| **Marigold** (1c gain 15/30 gold, FLOWER, Exhaust) | Free gold + FLOWER tag to trigger Plants. |
| **Shovel** (1c retrieve 1/2 FLOWER from exhaust, Exhaust) | Recovers Sunflowers/Twin_Sunflowers. |
| **Blover** (1c remove minions + 2 Weak+2 Vuln non-minions, PLANT, Exhaust) | Situational but game-winning vs minion fights. PLANT tag. |
| **Flower_Shooting** (2c 14/20, FLOWER, triggers ALL auto-targets) | Triggers every Plant and Danmaku in hand. Key enabler. |
| **Manipulating_flower** (1c draw all FLOWERS from deck, +Vigor per card drawn) | Fills hand with FLOWERS. Upgrade adds burst damage. |
| **Flower_danmaku** (1c 6/8, DANMAKU+FLOWER) | Dual-tag. Triggers Plants. Only DANMAKU worth having here. |
| **Crazy_yuuka** (1c power, every PLANT→add random PLANT to hand) | Infinite plant generation. Addictive. |
| **Fertilizer** (2c power, FLOWERS no longer exhaust) | Enables infinite Sunflower loops. Game-changing. |
| **Gensou_shunka** (1c power, each turn→random FLOWER to hand) | Consistent FLOWER supply. |
| **Watering** (1c shuffle discard→draw, upgrade: recover exhaust) | Recovers spent FLOWERS/PLANTS. |
| **Broken_flower** (2c, next attack ×3, Ethereal) | Pairs with Suika (15×3=45 from auto-trigger) or Repeater. |
| **Blossoming_of_Gensokyo** (2c 15/20, creates double-damage copy) | Strong standalone. FLOWER synergy. |
| **Small_suika** (1c 10/13, PLANT) | Generated by Suika. 3 merge into Suika. |
| **Smiling** (0c heal 4/6) | Sustain. |
| **Mature_gang** (2c power, draw 2/3 extra per turn) | Best generic draw power. Good in any deck. |
| **Plantern, Wall_nut, Tall_nut** | Any PLANT block card works. |

| Card | Why It Hurts |

| **Magic_cannon** | Triggers Danmaku, not Plants. Wastes the FLOWER trigger. |
| **Second_magic_cannon** | Same. Your FLOWER plays should trigger Plants, not cannons. |
| **Small_magic_cannon** | Same. Weak version of the same problem. |

| **Preemptive_attack** | PHYSICAL_ARTS. No PLANT/FLOWER tag. Dead card. |
| **Straight_punch** | PHYSICAL_ARTS. |

## Quick Start Cheat Sheet

| Want to... | Pick this School |
|------------|------------------|
| Big AoE damage every fight | Magic Cannon |
| Punch one enemy into dust | Physical Arts |
| Outlast with infinite value | Flower Garden |
| Easiest to pilot | Magic Cannon |
| Scales hardest into lategame | Physical Arts (Preemptive) |
| Most fun combos | Flower Garden (post-Fertilizer) |

## General Tips

1. **Remove basic Strikes first** — but keep Intimidation (good in any school), keep SMC (if going cannons)
2. **One Energy relic is usually enough** — Sunflower/Twin_Sunflower provide all the energy you need
3. **Don't mix schools early** — commit to one by Act 1 boss. Mixed decks draw dead cards.
4. **Plantern, Memory, Resist_offensive are generically good** — no tags required, work in any deck
5. **Exhaust cards are your friend** — removes chaff, keeps combos consistent
6. **Pick one school, ignore the rest** — if you're cannon, skip PHYSICAL_ARTS and PLANTS entirely
7. **Smiling (0c heal) is always safe** — no downside, free sustain
8. **Fragrance (0c E+draw) is always safe** — value in any deck
